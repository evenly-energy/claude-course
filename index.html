Autofullføring vs Agent

Autocomplete

Du skriver → AI foreslår Du velger → AI fortsetter Du styrer → AI følger Reaktiv. Linje for linje.

Agent

Du beskriver → AI planlegger → AI leser filer → AI endrer kode → AI kjører tester → AI committer Proaktiv. Oppgave for oppgave.

Harness-konseptet

Din logikk rundt Claude — du eier flyten.

→
Bygg prompt
→
Kjør Claude
→
Parse output
→
Valider
→
Lever / Retry

Harness-eksempel

harness.sh
#!/bin/bash
ISSUE="$1"
MAX_RETRIES=3

# 1. Hent oppgave
TASK=$(linear issue get "$ISSUE" --json)

# 2. Bygg prompt
PROMPT="Implementer: $(echo $TASK | jq -r .title)
Beskrivelse: $(echo $TASK | jq -r .description)"

for i in $(seq 1 $MAX_RETRIES); do
# 3. Kjør Claude
echo "$PROMPT" | claude -p \
--allowed-tools "Read,Write,Bash(npm test)" \
--max-turns 20

# 4. Valider
if npm test; then
git add -A && git commit -m "feat: $ISSUE"
break
fi
done

Raskere å iterere på tickets i Linear og validere planen enn å validere all kode.

- [ ] Refresh token flow works
- [ ] Failed login returns 401
