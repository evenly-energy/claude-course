Copilot vs Claude Code

Autocomplete

Du skriver → AI foreslår Du velger → AI fortsetter Du styrer → AI følger Reaktiv. Linje for linje.

Agent

Du beskriver → AI planlegger → AI leser filer → AI endrer kode → AI kjører tester → AI committer Proaktiv. Oppgave for oppgave.

┌──────────────────────────────────────────────────┐ │ Ditt harness (bash/python/ts) │ │ │ │ 1. Hent oppgave fra Linear/GitHub │ │ 2. Bygg prompt med kontekst │ │ 3. claude -p --output-format json ... │ │ 4. Valider output (tester, lint, schema) │ │ 5. Feilet? → Juster prompt, prøv igjen │ │ 6. OK? → Commit, push, opprett PR │ └──────────────────────────────────────────────────┘

Harness-eksempel

harness.sh
#!/bin/bash
ISSUE="$1"
MAX_RETRIES=3

# 1. Hent oppgave
TASK=$(linear issue get "$ISSUE" --json)

# 2. Bygg prompt
PROMPT="Implementer: $(echo $TASK | jq -r .title)
Beskrivelse: $(echo $TASK | jq -r .description)"

for i in $(seq 1 $MAX_RETRIES); do
# 3. Kjør Claude
echo "$PROMPT" | claude -p \
--allowed-tools "Read,Write,Bash(npm test)" \
--max-turns 20

# 4. Valider
if npm test; then
git add -A && git commit -m "feat: $ISSUE"
break
fi
done

Begrensninger

Ærlig om trade-offs.

  • Ingen tilgang til lokalt filsystem
  • Begrenset MCP-støtte
  • Sesjoner har begrenset levetid
  • Avhengig av nettverkstilgang
  • Kan ikke kjøre lokale verktøy (Docker, etc.)

Bruk remote for isolerte, selvstendige oppgaver — ikke for lokal utvikling.

Ingen resume & kvalitetsfall

Krasj = start på nytt

  • Ingen checkpoints
  • Ingen delresultater

Løsningen

Ralph-loopen

"I'm helping!"

Design for iterasjon, ikke perfeksjon.
Korte loops med ekstern validering.

┌──────────┐ ┌──────────┐ ┌──────────┐ │ Forsøk │────▶│ Valider │────▶│ Lær │ │ #1 │ │ (tester) │ │ (juster) │ └──────────┘ └─────┬────┘ └─────┬────┘ │ │ Feil? │ ┌─────┘ ▼ ▼ ┌──────────┐ │ Forsøk │ → Valider → OK? → Lever! │ #2 │ └──────────┘

Ikke mål AI på første forsøk — mål konvergens over tid.

ATDD — tester som sannhet

Tester definerer objektivt hva "ferdig" betyr.

settings.json
{
"hooks": {
"stop": [{
"command": "npm test",
"blocking": true
}]
}
}
  • Claude stopper → hook kjører tester
  • Tester feiler → resultat mates tilbake
  • Claude itererer til testene er grønne
